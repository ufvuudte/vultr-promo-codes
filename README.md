## 码填了没生效，按这个顺序排查

1. **核对字符**：有没有多空格、大小写和官方页是否完全一致。
2. **确认资格**：四个码都限新客户，已有账户、重复注册的账户都不符合。
3. **检查有效期和地区限制**：促销可能有时间窗，也可能对账户所在地区有要求。
4. **看支付方式**：账户没有绑定有效支付方式时，额度通常不会到账。
5. **刷新或重新登录**再 Apply 一次。
6. **联系支持**：让客服确认你的账户是否符合条件，比自己反复试快。
